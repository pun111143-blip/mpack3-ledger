# 📊 엠팩3 가계부 대시보드

엠팩3노래연습장 가계부(구글 시트 `📊 엠팩3노래연습장 가계부 2026`)를 **폰에서 한눈에** 보는 화면입니다.
시트에 매일 입력하면 이 화면이 그대로 따라옵니다.

- 주소: **https://pun111143-blip.github.io/mpack3-ledger/**
- 폰 홈 화면에 추가하면 앱처럼 전체화면으로 열립니다.
- 4자리 비밀번호로 잠깁니다.

## 화면에 나오는 것

| 영역 | 내용 |
| --- | --- |
| 월 선택 | `11월` · `12월` · `월별 추이` |
| KPI | 총매출 / 총지출 / 순익 + 일별 매출 막대 |
| 매출 비중 | 현금 · 카드 · 이체 금액과 % |
| 지출 구성 | ① 고정비 ② 물품비용(온라인·현장·주류음료) ③ 인건비 ④ 수리·관리비 — 4장, 눌러서 펼치기 |
| 일별 매출 | 1일~말일 현금·카드·이체·합계 표 |
| 월별 추이 | 월별 매출·지출·순익 비교 + 지출 4분류(①~④) |

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 전체 (스타일·동작 포함, 의존성 없음) |
| `Code.gs` | 구글 시트를 읽어 JSON으로 넘겨주는 Apps Script (아래 설치 안내) |
| `manifest.json`, `sw.js`, `icon-*.png` | 홈 화면 추가용 PWA 설정 |
| `SETUP.md` | 시트 연결 설치 안내 |

## 숫자는 어디서 오나

화면에 금액을 직접 적어 두지 않았습니다. 앱이 **Apps Script 웹앱(Code.gs)** 에 요청하면,
그 스크립트가 스프레드시트에서 값을 읽어 돌려줍니다. 그래서:

- 시트를 고치면 대시보드도 바뀝니다 (최대 5분 캐시, 새로고침 버튼으로 즉시).
- 저장소는 공개지만 **실제 금액은 저장소에 없습니다.** 비밀번호도 `Code.gs`가 아니라
  실제 배포본에만 들어갑니다.
- 읽기 전용입니다. 이 스크립트는 시트를 고치지 않습니다.

## 처음 설정

`SETUP.md` 를 따라 하면 5분이면 끝납니다. 요약하면:

1. 시트 → 확장 프로그램 → Apps Script → `Code.gs` 붙여넣기 → 비밀번호 수정
2. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → URL 복사
3. 폰에서 대시보드 열기 → [시트 연결 설정] → URL + 비밀번호 입력

## 잠금에 대해

공개 주소라서 4자리 비밀번호는 **잠금장치(남의 눈을 막는 정도)** 입니다.
정말 감춰야 하는 자료라면 비밀번호를 길게 쓰거나, 아예 이 화면을 사장님 폰에만
두는 쪽이 안전합니다. (민감한 숫자를 공개 페이지에 심지 않은 이유이기도 합니다.)
